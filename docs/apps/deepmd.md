# DeePMD

## About

[DeePMD-kit](https://github.com/deepmodeling/deepmd-kit) trains machine-learned interatomic potentials. Simmate's `deepmd` app currently provides `DeepmdDataset`, which converts structures with energies and forces from the Simmate database into DeePMD training inputs.

 - [GitHub Repository](https://github.com/deepmodeling/deepmd-kit)
 - [Official Documentation](https://docs.deepmodeling.org/projects/deepmd/en/master/)
 - [Research Paper](https://www.sciencedirect.com/science/article/pii/S0010465518300882)

--------------------------------------------------------------------------------

## Installation

1. Add `deepmd` to the list of installed Simmate apps with:
``` bash
simmate config add deepmd
```

2. (optional) To train models on these inputs, install DeePMD-kit using [their official documentation](https://docs.deepmodeling.org/projects/deepmd/en/master/).
