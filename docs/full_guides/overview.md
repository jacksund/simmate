# Full Guides

These guides provide a deep dive into how Simmate works. While the [Getting Started tutorials](../getting_started/introduction.md) cover the basics, these pages are for users who want to build custom tools, manage large calculations, or develop new software.

---

## The Simmate Stack

Simmate is built in layers, starting with a scientific toolkit and building up to automated workflows and web interfaces. These guides follow that structure from the top (user interfaces) to the bottom (core code):

1. **[Apps](apps/basic_use.md)**: Extensions that add support for new programs (like VASP) or custom features.
2. **[Website](website/setup_and_config.md)**: The user interface for viewing data and monitoring your work.
3. **[Workflows](workflows/basic_use.md)**: The compute engine that automates multi-step calculations and fixes common errors.
4. **[Compute](compute/basic_use.md)**: The system for running jobs on your local machine, clusters, or the cloud.
5. **[Database](database/basic_use.md)**: How scientific data is stored, organized, and searched.
6. **[Toolkit](toolkit/crystal_structures/overview.md)**: The core Python objects for molecules and crystal structures.
